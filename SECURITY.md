# Security Policy

Portal stores SSH credentials and encrypts them on disk. If something here is
wrong, it is worth telling us about properly.

## Reporting a vulnerability

**Please do not open a public issue for a security problem.**

Use GitHub's [private vulnerability reporting](https://github.com/nowte/portal/security/advisories/new)
on this repository, or email **aahmetemin888@gmail.com**.

Include what you can: what you found, how to reproduce it, which version or commit,
and what an attacker could do with it. A rough report is better than no report.

You will get a first response within **7 days** and, where a fix is needed, an
assessment within **30 days**. This is a solo project — if that slips, it is
bandwidth, not indifference. You are welcome to chase.

Please give us **90 days** before public disclosure, or less if a fix ships sooner.
You will be credited in the release notes unless you would rather not be.

## Supported versions

Pre-1.0, only the latest commit on `main` is supported. Once v1.0 ships, this
section will name real versions.

## What is in scope

- The encrypted vault: key derivation, encryption, the recovery phrase, anything
  that could expose secrets at rest.
- Credential handling in memory, and anything that writes a secret to disk in
  plain text.
- Host key verification (`known_hosts`), including the changed-key path.
- SSH, SFTP and tunnel handling in `portal-core`.
- The Tauri command bridge — anything that lets the web layer reach further into
  the core than it should.
- Any outbound network connection the user did not ask for.

## What is not in scope

- Vulnerabilities in an SSH server you connect to.
- Attacks that require an attacker to already have your unlocked machine.
- Missing hardening on a build you modified yourself.
- Reports generated by a scanner with no analysis attached.

## Known and documented

These are understood, written down, and not new findings:

- The encrypted vault's file header stores a device label and a timestamp in plain
  text. Contents are encrypted; that metadata is not.
- Uptime checks stop when the application is not running.
